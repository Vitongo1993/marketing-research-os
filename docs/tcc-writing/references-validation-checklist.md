# Core Rule

Every reference in the final list must pass three tests:

```text id="pr1eow"
1. Accuracy — the bibliographic information is correct.
2. Relevance — the source supports a specific part of the TCC.
3. Consistency — the citation and reference formatting are standardized.
```

If a reference does not pass these three tests, it should be corrected, replaced or removed.

---

# 1. General Reference Validation Checklist

For every reference, verify:

```text id="h8zq6s"
[ ] Author name is correct.
[ ] Author order is correct.
[ ] Publication year is correct.
[ ] Title is complete.
[ ] Subtitle is included, if applicable.
[ ] Edition is included, if required.
[ ] Journal title is complete, if article.
[ ] Volume is included, if article.
[ ] Issue/number is included, if article.
[ ] Page range is included, if article or chapter.
[ ] Publisher is included, if book.
[ ] City of publication is included, if required by institutional standard.
[ ] DOI is included, if available and required.
[ ] URL is included for online sources.
[ ] Access date is included for online sources.
[ ] Reference follows ABNT/institutional formatting.
[ ] The source is cited in the manuscript.
[ ] The source supports a specific argument in the manuscript.
```

---

# 2. Citation-to-Reference Consistency Checklist

For each in-text citation, confirm:

```text id="k7q3xv"
[ ] The cited author appears in the reference list.
[ ] The citation year matches the reference year.
[ ] Author spelling is identical in citation and reference.
[ ] Multiple-author citations are formatted consistently.
[ ] Direct quotations include page number.
[ ] Indirect citations do not require page number unless the institution requests it.
[ ] Every cited work has a complete reference entry.
```

For each reference entry, confirm:

```text id="l6z9cv"
[ ] The reference is cited at least once in the manuscript.
[ ] The reference is not included only as decorative bibliography.
[ ] The reference belongs to the theoretical, methodological or contextual foundation of the study.
```

# 5. Reference Accuracy Checklist by Type

---

## 5.1 Books

For every book, verify:

```text id="olv6o1"
[ ] Author surname and initials.
[ ] Full title.
[ ] Subtitle, if applicable.
[ ] Edition.
[ ] City.
[ ] Publisher.
[ ] Year.
[ ] Translator, if using translated edition.
[ ] Original title, if institution requires.
```

```text id="k4icbe"
AUTHOR. Title: subtitle. Edition. City: Publisher, Year.
```

Examples to validate:


# 7. References That May Be Removed

Remove or avoid references that:

```text id="n0vmuc"
[ ] Are not cited in the manuscript.
[ ] Do not support a specific argument.
[ ] Are redundant with stronger academic sources.
[ ] Are too generic for the topic.
[ ] Are reports used where academic sources are available.
[ ] Are blog posts or low-authority sources.
[ ] Are not verifiable.
[ ] Have uncertain authorship or publication date.
```

Do not include references only to make the bibliography look larger.

---

# 8. References That Need Special Caution

---

## 8.1 AI References

Use AI references carefully.

The Telex case should not be overstated as advanced AI.

Use AI literature only to discuss:

```text id="q3ojk1"
automation-supported service
hybrid human-automation interaction
AI as broader marketing context
limits of automation in services
```

Avoid claiming:

```text id="gxkp8k"
AI decision-making
autonomous AI
AI-based diagnosis
AI-driven sales optimization
advanced artificial intelligence implementation
```

unless technically proven.

---

## 8.2 CAC and Cost References

Use marketing metrics references carefully.

The study calculates estimated operational cost, not full CAC.

If citing marketing metrics, use them for:

```text id="ggyu5s"
conversion rates
efficiency metrics
funnel analysis
performance measurement
```

Do not use them to imply full CAC if media and other acquisition costs were not included.

---

## 8.3 Healthcare and Hearing References

Use healthcare or hearing-sector references only if they add context.

Do not expand the TCC into a health sciences study.

The core of the TCC remains:

```text id="mdjo7r"
Marketing
Customer Journey
CRM
Lead Management
Automation
Services
```

# 9. ABNT Formatting Checklist for References

Before finalizing, verify:

```text id="dq905e"
[ ] Surnames are in uppercase, if required.
[ ] Authors are separated consistently.
[ ] Titles use correct capitalization.
[ ] Journal titles are not abbreviated unless allowed.
[ ] Book titles are formatted consistently.
[ ] Edition numbers are included when needed.
[ ] Page ranges use the same format.
[ ] DOI format is consistent.
[ ] URLs are preceded by the required expression.
[ ] Access dates follow the same format.
[ ] References are alphabetically ordered.
[ ] Spacing follows institutional rules.
[ ] Hanging indentation is applied if required.
```

---

# 10. In-Text Citation Formatting Checklist

Choose one style and use it consistently.

Examples:

```text id="fvklnu"
(Lemon; Verhoef, 2016)
Lemon e Verhoef (2016)
(Payne; Frow, 2005)
Payne e Frow (2005)
```

Checklist:

```text id="fzgcmh"
[ ] Use semicolon between authors in parenthetical citations.
[ ] Use “e” between authors in narrative citations in Portuguese.
[ ] Use “et al.” consistently for more than three authors, if allowed.
[ ] Use page numbers for direct quotations.
[ ] Avoid long direct quotations unless necessary.
[ ] Match citation year with reference entry.
```

---

# 11. Direct Quotation Checklist

Direct quotations should be rare.

Use direct quotation only when the original wording is essential.

For every direct quotation:

```text id="lbqynv"
[ ] Exact wording checked.
[ ] Author included.
[ ] Year included.
[ ] Page number included.
[ ] Quotation marks used for short quote.
[ ] Long quote formatted according to ABNT/institutional standard.
[ ] Translation is identified, if translated by the author.
```

Recommended approach:

```text id="rjpmk4"
Prefer paraphrased indirect citations.
```

# 12. Final Reference List Construction Workflow

Follow this order:

```text id="k48bk2"
Step 1 — List all citations planned in cited-manuscript-prep.md.
Step 2 — Validate high-priority references first.
Step 3 — Validate methodology references.
Step 4 — Validate service marketing and CRM books.
Step 5 — Validate AI and automation articles.
Step 6 — Validate reports only if they remain in the manuscript.
Step 7 — Remove uncited or unnecessary references.
Step 8 — Format remaining references in ABNT/institutional style.
Step 9 — Cross-check citations against reference list.
Step 10 — Insert final references into final-manuscript-with-citations.md.
```

# Final Summary

This checklist ensures that the TCC reference base is accurate, relevant and academically defensible.

The most important validation priorities are:

```text id="j3fzl1"
1. Validate all high-priority academic references.
2. Remove unused or decorative references.
3. Match every in-text citation with the final reference list.
4. Use reports only as contextual support.
5. Keep internal Telex data as internal source notes, not academic references.
6. Ensure ABNT and institutional formatting consistency.
```

Once this checklist is complete, the project can move safely into final data validation and then into the cited manuscript version.
