# Purpose

This document defines the recommended tables, figures, diagrams and visual elements to be included in the final MBA Final Project.

Its purpose is to organize all visual and tabular elements before assembling the final manuscript, ensuring that each table or figure has a clear analytical function, appropriate placement, consistent formatting and proper source attribution.

This document should be used together with:

```text id="tf01jq"

telex/operational-flow.md

```

---

# Core Rule

Every table and figure must serve a clear purpose.

Do not include visual elements only to make the TCC look more complete.

Before adding any table or figure, ask:

```text id="uekhka"
What does this table or figure help the reader understand?
```

If the answer is unclear, the element should not be included.

---

# Recommended Visual Strategy

The final TCC should use tables and figures to support four goals:

```text id="md9x2g"
1. Explain the research design.
2. Clarify the operational journey.
3. Present funnel data clearly.
4. Support comparison between the 2024 and 2025 models.
```

Tables should be used for:

* classifications;
* indicators;
* comparisons;
* hypotheses;
* costs;
* conversion rates.

Figures should be used for:

* customer journey flows;
* operational flows;
* conceptual models;
* process architecture.

---

# General Formatting Rules

All tables and figures should follow institutional and ABNT-based formatting rules.

General checklist:

```text id="0u2m2u"
[ ] Number tables sequentially.
[ ] Number figures sequentially.
[ ] Use clear and descriptive titles.
[ ] Mention every table or figure in the text before showing it.
[ ] Include the source below every table or figure.
[ ] Use consistent terminology.
[ ] Avoid confidential information.
[ ] Keep visual elements readable.
[ ] Ensure tables and figures fit within page margins.
[ ] Avoid excessive colors or decorative formatting.
```

Suggested source labels:


or:

# Data Validation Checklist for Tables

Before including quantitative tables, validate:

```text id="cfxx9r"
[ ] Are 2024 and 2025 periods equivalent?
[ ] Are data sources the same across periods?
[ ] Are leads counted consistently?
[ ] Are appointments counted consistently?
[ ] Are cancellations treated consistently?
[ ] Are no-shows separated from attendance?
[ ] Are sales attributed consistently?
[ ] Are duplicated leads removed?
[ ] Are bot-abandoned contacts included or excluded?
[ ] Are the cost values operational estimates only?
[ ] Are paid media costs excluded?
[ ] Are store costs excluded?
[ ] Are all formulas checked?
```

# Confidentiality Checklist for Visual Elements

Before including any table or figure, check:

```text id="nhk5pq"
[ ] No customer names appear.
[ ] No phone numbers appear.
[ ] No individual health information appears.
[ ] No employee-level sensitive data appears.
[ ] No confidential compensation information appears without authorization.
[ ] No system credentials or private URLs appear.
[ ] No screenshot includes sensitive data.
[ ] Store-level data are aggregated unless authorized.
[ ] Internal process details are approved for academic use.
```

# ABNT and Formatting Checklist

For each table:

```text id="6oc18i"
[ ] Title appears above the table.
[ ] Table is numbered sequentially.
[ ] Source appears below the table.
[ ] Table is referenced in the text.
[ ] Decimal and percentage formatting is consistent.
[ ] Currency follows Brazilian formatting if the final text is in Portuguese.
```

For each figure:

```text id="0pagkr"
[ ] Title follows institutional placement rule.
[ ] Figure is numbered sequentially.
[ ] Source appears below the figure.
[ ] Figure is referenced in the text.
[ ] Text inside the figure is readable.
[ ] Figure does not exceed page margins.
```

# Final Recommendation

The final TCC should use tables and figures strategically, not excessively.

Recommended final balance:

```text id="wji2si"
6 to 8 tables
4 to 5 figures
```
