# Purpose

This document provides a practical ABNT formatting checklist for the final MBA Final Project.

Its purpose is to guide the final formatting review of the TCC before submission, ensuring that structure, citations, references, tables, figures, margins, spacing and academic presentation follow the required institutional and ABNT-based standards.

This checklist should be used after the final manuscript has been assembled and before sending the document to the academic advisor or submitting the final version.

---

# Important Note

ABNT standards should always be applied together with the specific formatting manual provided by the institution.

If the MBA program, UFRJ, department, professor or advisor provides a template or formatting guide, that institutional guide should be treated as the primary source for final formatting decisions.

Use this document as a working checklist, not as a replacement for the official institutional rules.

# 2. Page Formatting Checklist

Confirm the basic visual formatting of the document.

```text id="mi2pum"
[ ] Paper size: A4
[ ] Orientation: portrait
[ ] Margins follow institutional/ABNT requirements
[ ] Font follows institutional requirements
[ ] Font size follows institutional requirements
[ ] Line spacing follows institutional requirements
[ ] Paragraph indentation is consistent
[ ] Text alignment is consistent
[ ] Page numbering follows institutional requirements
[ ] Page breaks are correctly inserted between main sections
[ ] No blank pages appear unintentionally
```

Common ABNT-based academic formatting usually uses:

```text id="c6kcnc"
A4 paper
Font size 12 for main text
Font size 10 for long direct quotations, footnotes, captions and sources
1.5 line spacing in main text
Single spacing in long quotations, footnotes, references, captions and sources
```

However, the institutional manual should always be checked before final submission.

# 4. Page Numbering Checklist

Check whether page numbering follows the required format.

```text id="f9zx4l"
[ ] Pre-textual elements are counted according to institutional rules
[ ] Page number display starts on the correct page
[ ] Page number is positioned according to institutional rules
[ ] Numbering is sequential
[ ] No page number is missing after section breaks
[ ] Appendices and annexes follow numbering rules
```

Common practice:

```text id="tbxqm0"
Pre-textual pages are counted but page numbers are usually not displayed until the textual section.
```

Always confirm with the institutional manual.

---

# 5. Section Numbering Checklist

Check section numbering and hierarchy.

```text id="xndvnb"
[ ] Main chapters are numbered correctly
[ ] Subsections follow logical hierarchy
[ ] Numbering does not skip levels
[ ] Titles are clear and concise
[ ] All headings appear correctly in the summary
[ ] Heading formatting is consistent
[ ] No heading is isolated at the bottom of a page
```

Suggested hierarchy:

```text id="btfodb"
1 INTRODUCTION
1.1 Research Problem
1.2 Objectives
1.2.1 General Objective
1.2.2 Specific Objectives
```

Avoid excessive heading depth.

Prefer a maximum of:

```text id="hk9haf"
three or four heading levels
```

unless the institutional manual allows more.

# 8. Citation Formatting Checklist

Check all citations in the body of the text.

```text id="kwgt7w"
[ ] All theoretical claims have citations
[ ] All methodology claims have citations
[ ] All direct quotations include page number
[ ] All indirect citations follow the selected ABNT style
[ ] Author names are spelled consistently
[ ] Citation years are correct
[ ] Every cited work appears in the reference list
[ ] No reference appears in the list without being cited, unless allowed by the institution
[ ] Citations are not excessive
[ ] Citations support the exact argument being made
```

---

## 8.1 Indirect Citation Checklist

Example format:

```text id="fpsyqk"
(Lemon; Verhoef, 2016)
```

or:

```text id="kc4cte"
Lemon e Verhoef (2016) afirmam que...
```

Checklist:

```text id="nxx7kd"
[ ] Author-date format is consistent
[ ] Semicolon use between authors is consistent
[ ] Year is correct
[ ] Citation supports the sentence
[ ] Citation appears before or after the correct statement
```

---

## 8.2 Direct Citation Checklist

For short direct quotations:

```text id="hvw1e8"
[ ] Quotation marks are used
[ ] Author is cited
[ ] Year is cited
[ ] Page number is cited
[ ] Quotation is reproduced exactly
```

For long direct quotations:

```text id="cuwska"
[ ] Quotation is formatted as a block quote
[ ] Font size follows institutional rules
[ ] Line spacing follows institutional rules
[ ] Indentation follows institutional rules
[ ] No quotation marks are used if required by the selected style
[ ] Author, year and page are included
```

Recommendation:

```text id="oeqgu4"
Prefer indirect citations throughout the TCC.
Use direct quotations only when the original wording is essential.
```

Confirm that the study does not incorrectly present operational cost as CAC.

```text id="habnwo"

[ ] Paid media costs are not included in operational cost
[ ] Store costs are not included unless clearly stated
[ ] Benefits, taxes and overhead are not included unless clearly stated
[ ] The term estimated operational cost is used consistently
[ ] Limitations of the cost analysis are clearly stated
```

Preferred wording:

```text id="xy42ol"

estimated operational cost per appointment
estimated operational cost per attendance
estimated operational cost per sale
```


# Final Summary

This checklist should be used as the final formatting and quality-control guide before submission.

The most important points are:

```text id="yf3q8z"
1. Follow the institutional manual first.
2. Keep citations and references consistent.
3. Validate all data.
4. Avoid causal overstatement.
5. Distinguish operational cost from CAC.
6. Remove confidential information.
7. Review the exported PDF carefully.
```

The TCC should only be considered ready when the academic content, citation system, formatting and final PDF have all been reviewed.
